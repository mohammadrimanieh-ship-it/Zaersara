# زائرسرا مشهد — نسخه اولیه 0.1.0

اپ اندروید چندکاربره برای مدیریت ۵ سوئیت و یک سالن زائرسرا.

## امکانات نسخه اول
- ۳ سوئیت ۵ نفره، ۲ سوئیت ۶ نفره و سالن ۱۴ نفره
- ورود چند کاربر با Supabase Auth
- رزرو مستقل هر واحد با تاریخ ورود و خروج
- جلوگیری دیتابیسی از رزرو هم‌پوشان یک واحد
- رزرو خانوادگی/فردی یا کاروانی با نام و تماس سرپرست
- ثبت همه زائران با کد ملی اجباری
- تشخیص سابقه و تعداد اقامت با جست‌وجوی کد ملی
- اقامت رایگان یا پولی، مبلغ و وضعیت پرداخت
- ثبت توضیحات و نگهداری کاربر ثبت‌کننده در دیتابیس
- ساختار آماده توسعه و versionCode/versionName برای آپدیت‌های بعدی

## راه‌اندازی آنلاین
1. یک پروژه در Supabase بسازید.
2. SQL Editor را باز کنید و فایل `backend/schema.sql` را کامل اجرا کنید.
3. در Authentication حداقل یک کاربر ایمیل/رمز بسازید.
4. برنامه را اجرا کنید و در صفحه تنظیمات، Project URL و anon/public key را وارد کنید.
5. با همان کاربر وارد شوید.

> کلید service_role را هرگز داخل اپ وارد نکنید. فقط anon/public key استفاده شود.

## نکته تاریخ
نسخه 0.1 تاریخ را با قالب `YYYY-MM-DD` ذخیره می‌کند تا دیتابیس دقیق و قابل توسعه بماند. رابط تقویم شمسی کامل برای نسخه بعدی در نظر گرفته شده است؛ دیتابیس نیاز به تغییر نخواهد داشت.

## توسعه بعدی پیشنهادی
تقویم شمسی گرافیکی، ویرایش/لغو/جابه‌جایی رزرو، لیست واحدهای خالی بر اساس بازه، نقش مدیر/کاربر، گزارش‌های سالانه، خروجی Excel/PDF، ثبت پرداخت‌ها و لاگ کامل تغییرات.
